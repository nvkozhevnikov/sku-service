Подключение VK
Целевое сообщество: sterbrust · 68800619. Ключи хранятся на этом компьютере в зашифрованном виде.
Проверка фото получает адрес загрузки; фотографии и посты не отправляются.
Автоматические фото
  1. Получите пользовательский API-ключ администратора для своего приложения VK с правами wall и photos.
  2. Вставьте ключ в защищённое поле ниже. Можно вставить полный результат официальной авторизации oauth.vk.com/blank.html.
  3. Studio проверит права и сервер загрузки. Ни фото, ни пост при этом не отправляются.
Ключ сообщества и обычный вход VK ID не заменяют пользовательский доступ к photos. Studio не может выпустить его из ключа сообщества.
Подключить автоматическую загрузку фото
Нужен ключ администратора этого сообщества с разрешениями wall и photos. Обычный вход через VK ID не гарантирует эти разрешения. Используйте только официальный способ выдачи ключа для вашего приложения; пароли и cookie не нужны.
Не присылайте ключ в чат. После проверки поле очищается.
