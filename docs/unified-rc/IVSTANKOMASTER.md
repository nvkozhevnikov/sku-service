# Ивстанкомастер

Адаптер `ivstankomaster` собирает открытые разделы `/category` и карточки
`/item`. Штатное задание использует очередь, ограничения домена и остановку.
Кнопка «Начать парсинг» на странице этого поставщика обходит каталог целиком
до заданного лимита. Для первоначального сбора укажите 50 карточек, паузу от
2 до 3 секунд. Одновременных запросов к сайту один. Перенаправления на другие
домены, неизвестные ссылки пагинации и неоднозначная идентификация отклоняются.

## Источник данных

- Собственная карточка подтверждается заголовком в хлебных крошках и кнопкой
  покупки той же карточки. Ключ товара берётся из `data-id`. Поле
  `data-article` рассматривается как обозначение модели. Суффиксы
  исполнений и «ПЛЮС» существенны.
- Коммерческая цена берётся из блока описания и хранится **с НДС**. Суммы
  с явным указанием НДС проверяются на противоречия. Для формата
  «без НДС / вторая сумма» поддерживается документированный порядок цен
  поставщика. Первая сумма должна совпасть с ценой покупки, а вторая
  быть больше. Данные без доказательства НДС получают статус review.
- Остаток берётся из `data-allcount`. Пустое значение означает, что наличие
  не подтверждено. Описания, свойства и адреса фотографий извлекаются
  из собственной карточки.

## Применение

1. Обновить установку с ветки `feature/sterbrust-autonomous-system-20261026`.
2. На согласованной рабочей БД штатно применить `021_ivstankomaster_supplier.sql`.
   Она регистрирует источник выключенным и сохраняет его настройки при повторном запуске.
3. Проверить режим ручного сбора по [общей инструкции](MANUAL_COLLECTION.md).
   В панели администратор открывает «Поставщики → Ивстанкомастер», задаёт
   паузу 2–3 секунды и лимит 50 карточек, затем нажимает «Начать парсинг».
   После завершения сверить итог задания и данные источника. На 24.11.2026
   сайт отдавал 19 карточек. Количество может меняться.

Для добавления поставщика к действующей установке новый дамп БД не нужен.
Миграция регистрирует источник, штатный сбор сохраняет карточки и цены.

Новый поставщик не расширяет исторические контракты LIVE11, их матрицу и
пределы. Автоматическое применение новых сопоставлений остаётся выключенным.
Неподтверждённые предложения не участвуют в выборе для выгрузки сайта.
В разделе «XML-выгрузка» полный XML поставщика показывает его сохранённые
предложения с НДС, пока они ожидают сопоставления.

## Связи и спорные позиции

В изолированной PostgreSQL проверены три ручные связи. Список в
[IVSTANKOMASTER_REVIEW_DECISIONS.json](IVSTANKOMASTER_REVIEW_DECISIONS.json)
служит инструкцией для оператора. Приложение не применяет решения из файла.
Перед ручным подтверждением сверить `data-id` внутри `ivstankomaster`,
активность и исполнение товара Sterbrust, а также существующую связь.
Если карточки проверки нет, сначала проверить результат сопоставления по
источнику. Массовое применение для переноса этих решений не требуется.

| Карточка поставщика | Sterbrust ID | Решение |
|---|---:|---|
| 1 · СЗТП 600Т | 18041 | Подтверждение проверено. Диаметр пил 140–700 мм, в таблице из снимка Sterbrust указано 140–170 мм. |
| 2 · СЗТП 600Тл | 18042 | Подтверждение проверено для базовой модели. ПЛЮС выделен в отдельную позицию. |
| 4 · СЗТП 600А | 18040 | Подтверждение проверено. Уточнить габариты и наличие оснастки для малых пил в комплекте. |
| 9 · СЗПН 630 | 31667 | Сверить исполнение. Расходятся мощность и размеры ножа. У производителя указаны две максимальные длины, 630 и 640 мм. |
| 5 · СЗТП 600Ал | 31683 | Сверить комплект. Поставщик продаёт стойку М и тумбу с СОЖ отдельно. В снимке Sterbrust стойка заявлена в комплекте. |
| 8 · СЗПН 630А | 34726 | Неактивная карточка в снимке. 550 Вт в реестре и 1100 Вт у производителя. |

Семь кандидатов на добавление и ещё шесть спорных позиций оснастки
перечислены в JSON. Перед созданием карточек проверить текущий реестр.
Решения основаны на снимке Sterbrust от 20.11.2026 и сохранённых карточках
поставщика от 24.11.2026.

## Контрольные XML от 24.11.2026

В полном XML 19 карточек с НДС. Старый `ivstankomaster_linked_vat.xml`
содержит четыре исходных кандидата. Актуальный файл для сверки
`ivstankomaster_linked_vat_qa.xml` содержит три действующие связи из
изолированной БД. Оба файла относятся к данным на дату сбора.
Импорт ESOL остаётся отключённым.

Повторная сборка по зафиксированным данным:

```text
python -B scripts/build_ivstankomaster_export.py CAPTURE_DIR STERBRUST_REGISTRY.jsonl NEW_OUTPUT_DIR
```

Команда воспроизводит исходный разбор и первичный список кандидатов.
Ручные связи она не применяет. Файлы связаны с SHA256 исходных ответов
и временем наблюдения.
