same app_users and signer, five application profiles (ADMIN, SUPPLIER_MANAGER,

the authenticated no-store response. Own-password change works for every role,
checks confirmation/complexity/current password and revokes previous sessions.
Changing permissions revokes affected sessions. Last active ADMIN protection uses
a transaction-wide advisory lock shared by role and activation changes.

an additional restriction: a custom permission does not elevate the underlying
OPERATOR/VIEWER contract. New endpoints must be added to the permission map and
tested for CSRF, horizontal and vertical access. ADMIN permissions are immutable.
