# Импорт ссылок в локальную Content Studio

Этот необязательный модуль помогает, когда защита Sterbrust не отдаёт страницу программному запросу. Он использует обычную сессию вашего браузера и передаёт в локальную Studio только название и область описания/характеристик. Открывает свою неактивную вкладку и закрывает только её. Ничего не публикует, не нажимает кнопки сайта, не читает пароли, cookie или другие сайты.

Установка выполняется оператором один раз. В Chrome/Яндекс откройте страницу управления расширениями, включите режим разработчика, выберите «Загрузить распакованное расширение» и укажите эту папку. Проверьте разрешения: чтение Sterbrust и локальной страницы 127.0.0.1. Модуль принимает сообщения только с корня на портах58206/58207 либо с `/content-studio/` на58161/58162. Другие страницы панели и сайты не разрешены. Для работы откройте Studio в том же браузере и обновите её страницу. Установка в пользовательский браузер этим пакетом не выполняется.

После установки вставьте URL товара в поле подготовки. Studio обнаружит модуль, прочитает название/описание/характеристики и подставит ссылку публикации. Ссылку можно заменить или удалить. До нажатия подготовки текст в ИИ не передаётся.

Если страница просит вход/подтверждение защиты, откройте её обычным способом и выполните необходимые действия сами. Модуль не обходит авторизацию и не решает CAPTCHA. Удаляется через обычную страницу расширений браузера.
