# Как передать публичную страницу YouMet

Статус: **YOUMET_OPERATOR_CAPTURE_READY**. Сохранённая оператором страница ещё
не предоставлена. Тестовые файлы и прежний автоматический снимок не используются
как операторское подтверждение YouMet.

## Подготовка файла

1. Откройте нужную общедоступную страницу `https://youmet.ru/` в обычном браузере,
   без входа в личный кабинет. Если вместо магазина показана защита/CAPTCHA,
   такой снимок не подходит; решать или обходить её для этой задачи не нужно.
2. Сохраните страницу как HTML. Подходят «HTML only» и обычное «Сохранить страницу».
   Достаточно одного `.html`: папка изображений/ресурсов не импортируется.
   Другой вариант: DevTools → Copy outerHTML корневого элемента `html`, затем
   сохраните текст в `.html` (предпочтительно UTF-8). Скриншот не требуется.
3. Вместе с файлом укажите **исходный URL** и **время показа/захвата с часовым поясом**.
   Время изменения файла не заменяет время захвата. Например,
   `2026-10-12T12:00:00+03:00` — только пример формата, используйте фактическое время.

Можно предоставить только главную, только акцию, новость, блог или товарную
страницу. Все страницы одновременно не нужны. Пути из навигации остаются
DISCOVERED_NOT_FETCHED, пока не предоставлен HTML соответствующей страницы.

Не передавайте cookies, заголовки запросов, пароль, профиль браузера или HAR.
HAR/JSON не поддерживаются в этом этапе. Входной HTML остаётся без изменений;
хранится только очищенная копия без скриптов, форм, служебных атрибутов, активных
ресурсов и распознанных секретов. Видимые персональные/авторизационные цены не
превращаются в публичную распродажу. Источник принимает только основной youmet.ru.

## Импорт

Из `D:\documents\personal\ChatGPT\Стербруст\work\sterbrust-competitive-intelligence`
выполните команду, заменив путь к файлу, URL и время:

```powershell
& '.\.venv\Scripts\python.exe' -m competitor_intel --dev-config 'competitor-data\dev-config.json' import-browser-capture `
  --source youmet `
  --url 'https://youmet.ru/' `
  --file '<путь-к-сохранённой-странице.html>' `
  --capture-time '2026-10-12T12:00:00+03:00' `
  --report-output 'D:\documents\personal\ChatGPT\Стербруст\reports\COMPETITOR_BUSINESS_REPORT_PREVIEW_2026-10-12'
```

Команда не открывает сайт и не вызывает ИИ. Используется только существующая
изолированная competitor DB55454. Службы/БД автоматически не запускаются.
Секретный dev-config не копируется в результат и не публикуется.

Автоматическое определение типа поддерживает уже наблюдавшиеся `/akcia/`,
`/about/news/`, `/blog/`, `/shop/` и главную. Для другой реально наблюдаемой структуры
можно явно указать `--kind PROMOTION`, `NEWS`, `BLOG`, `SALE_PAGE` или `PRODUCT_DETAIL`.
Путь к неизвестному разделу не генерируется и не запрашивается.

При первом принятом снимке — INITIAL BASELINE. Его происхождение обозначается
OPERATOR_BROWSER_CAPTURE / OPERATOR_CAPTURE / PUBLIC_BROWSER_EVIDENCE в хранении,
HTML и экспортированных строках CSV. Это операторское публичное свидетельство,
а не успешный автоматический HTTP-запрос. Исходный 403 сохраняется отдельно.
После принятого снимка тот же общий HTML на шесть конкурентов обновляется автоматически.

Одинаковый HTML не создаёт повторную версию. Изменённый очищенный HTML создаёт
новую версию. Более старый снимок той же страницы не заменяет более свежий:
снимки одной страницы импортируются по времени захвата. Отдельные NEWS и BLOG
сохраняют собственные даты; даты связанных материалов не подставляются.
Снимки вне исходного периода с 01.09.2026 сохраняются как evidence, но не попадают
в текущие бизнес-метрики. Неизвестные поля остаются неизвестными.
Регион цены берётся из показанного на странице текущего города; если он
не определён, дневное сравнение цен между такими снимками не выполняется.

## Ограничения проверки

Парсер товарных карточек/навигации основан на ранее сохранённом обычном DOM
YouMet; обработка страниц акций/новостей/блога проверена на синтетических fixtures.
Реальные detail-layouts будут проверяться по предоставленным страницам. Если
страница не содержит нужных полей, её данные не дополняются догадками.
Нет OCR, screen scraping, CAPTCHA solving, login automation или обхода защиты.
KAMI404 `/spec/skidka-do-30-kley/` остаётся ERROR / ACTUAL_ACCESS_FAILURE и не
считается блокером KAMI onboarding. Остальные источники не перечитываются.
